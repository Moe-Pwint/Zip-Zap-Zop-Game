This is a group game called "Zip Zap Zop" recreated for web.
Game will have many levels.
A new level will unlock only after successfully pass the previous level. But, player can go back to play previous levels.
Each Level Btn has Icons next to them. First Icon showing time limit. Subsequent icons showing additional features (e.g. amt of cards).

- Start Screen
  - Logo Screen (for loading)

  - About Game Button
    1. Tap the cards "Zip", "Zap", "Zop" in a row quickly without making a mistake.
    2. Replay to beat your own records!
    3. During each tap, the cards will randomly switch places.
    4. Each level has different rules.
  - Select Level Button (Each level )
    1.  Level 1 Btn
        - Level 1 Rules:
          Tap the cards "Zip" "Zap" "Zop" in a row without making a mistake.
          Gain 20 scores in 60 seconds to win the level.
          Beat your own time!
          - Play Level 1 Btn.

    2.  Level 2 Btn
        - Level 2 Rules:
          Tap the cards "Zip" "Zap" "Zop" in a row without making a mistake.
          Time limit for each tap: 2 seconds
          Gain minimum 30 scores in 60 seconds to win the level.
          Beat your own score!
        - Play Level 2 Btn.

    3.  Level 3 Btn
        - Level 3 Rules:
          Tap the cards "Zip" "Zap" "Zop" in a row without making a mistake.
          Time limit for each tap: 2 seconds
          Gain minimum 30 scores in 60 seconds to win the level.
          Beat your own score!
          Watch out for an additional card with a typo!
          - Play Level 3 Btn.

    4.  Level 4 Btn
        - Level 4 Rules:
          Tap the cards "Zip" "Zap" "Zop" in a row without making a mistake.
          Time limit for each tap: 1 seconds
          Gain minimum 30 scores in 30 seconds to win the level.
          Beat your own score!
        - Play Level 4 Btn.

    5.  Level 5 Btn
        - Level 5 Rules:
        - Level 4 Rules:
          Reverse pattern: Tap the cards "Zop" "Zap" "Zip" in a row without making a mistake.
          Time limit for each tap: 1 seconds
          Gain minimum 30 scores in 30 seconds to win the level.
          Beat your own score!
        - Play Level 5 Btn.

- UI for every level
  1. menu icon
     - Back to Main Screen
     - Level Description
     - Start over
     - Profile (stats for each level, others)
  2. menu icon
  3. Highest Score || Best Time
  4. score
  5. Game time countdown
  6. timer countdown
  7. cards

- Game Functions for level 0

- Profile
  - Stats Section
    - Fastest recorded tapping time: (eg.)0.1 second (announce at the end of level if record is beaten)
    - Stats for each level (highest score, longest time played)
